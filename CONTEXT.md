# Context: Product Design Craft

The single bounded context for this repo. `docs/agents/domain.md` tells the
engineering skills to read this file before exploring, and to use its
vocabulary in issue titles, test names and refactor proposals.

## What this is

A Next.js application for product design craft work. The scaffold is in place;
the product itself is not built yet.

## Glossary

The glossary is deliberately empty. Terms get added by `/domain-modeling` when
they are actually resolved during work — not invented up front. When you need a
concept that isn't here, that is a signal: either you are inventing language the
project doesn't use, or there is a real gap worth recording.
